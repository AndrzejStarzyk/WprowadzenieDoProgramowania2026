1. Na pulpicie znajdź ikonę z nazwą 'Pracus' i uruchom ten program (jeśli nie jest włączony automatycznie).
2. Otwórz przeglądarkę (preferencyjnie firefox) i przejdź na stronę `kmolenda.github.io/jupy`
3. Wybierz xPython 3.13
3. W osobnej karcie otwórz `https://github.com/AndrzejStarzyk/WprowadzenieDoProgramowania2026`
4. Przejdź do lab1 -> lab1.ipynb i pobierz ten plik (ikonka ze strzałką w dół)
5. Przeciągnij pobrany plik do środowiska Pythonowego
6. Utwórz własne konto na GitHub Education wykorzystując uczelniany adres email i dane z legitymacji (?)
7. Stwórz nowe repozytorium (ikona top-left -> repositories -> new) - wybierz nazwę i zmień public na private
7. Wykonaj zadania z lab1.ipynb
8. Pobierz edytowany notatnik (file -> download)
9. Prześli go repozytorium Add file -> upload files
10. Usuń pobrane notatniki z komputera, zresetuj środowisko pyhonowe
