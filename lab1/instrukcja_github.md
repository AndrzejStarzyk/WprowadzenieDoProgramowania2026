# Postawowe komendy github

1. Sklonuj repozytorium https://github.com/AndrzejStarzyk/WprowadzenieDoProgramowania2026, `git clone https://github.com/AndrzejStarzyk/WprowadzenieDoProgramowania2026.git wdp` (zamiast wdp można wybrać bardziej odpowiednią nazwę).
2. Załóż własne konto na github.
3. Podążając za wskazówkami z dokumentacji https://docs.github.com/en/get-started/using-github/hello-world stwórz nowe repozytorium dla swojego kodu oraz branch.
4. Z pomocą dokumentacji https://git-scm.com/cheat-sheet sklonuj repozytorium, wejdź (checkout) na odpowiednią gałąź (branch).
5. W lokalnym środowisku dokonaj jakiejś zmiany, np. dodaj plik. Następnie dodaj do zmian ten plik.
6. Za commituj i zpushuj zmiany.
7. Z pomocą pierwszej instrukcji otwórz pull request stworzonego brancha do main, oraz go zmerge'uj.
8. Znowu lokanie przejdź na branch main, wykonaj polecenie `git fetch` i `git pull` i upewnij się na main pojawiły się zmiany wykonane na osobnym branchu.
