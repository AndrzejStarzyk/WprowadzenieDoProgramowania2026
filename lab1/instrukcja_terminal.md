# Postawowe komendy linux

1. Otwórz terminal i wpisuj następujące polecenia
2. `pwd` - obecna ścieżka
3. `mkdir project` - stwórz katalog 'project'
4. `cd ./project` - przejdź do katakogu projekt ( `cd ..` aby wrócić)
5. `touch main.py` - stwórz plik pythonowy
6. `python --version` - zweryfikuj wersję pythona 
7. `python ./main.py` - uruchom program pythonowy

8. `python -m venv source` - stwórz wirtualne środowisko pythonowe dla przygotowanego projektu
9. `./source/scripts/activate` - aktywuj środowisko (`deactivate` aby dezaktywować)
